money converter Pro
My app is a full-stack currency converter, built with next.js, that lets users convert world currencies using live exchange rate or prevailing rate.

I built this project to demonstrate :
* working with APIs.
* handling real time data.
* building a more consistent and responsive UI with Next.js, React, Tailwind CSS.
* improving a legacy currency converter built with C#, HTML and CSS.
* hands on experience with modern full-stack patterns using React and Next.js.

The features, include :

Next.js full-stack architecture
Real time conversion using live API.
Instant updates as users make input.
Smooth non-blocking UI using async/await for API requests.
Error handling state.
Currency dropdown from API

Teck Stack

Next.js(App Router)
Typescript
React
Tailwind CSS
Frankfurter API

Lessons Learned

Next.js full-stack architecture
API integration
State management in React
Separation of concern - server/client separation
